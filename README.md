# gag

An Android app for downloading videos, photos and music, with downloads that keep running in the background and a share menu option so you can send links straight to it.

## Download

Get **gag.apk** from the [latest release](../../releases/latest) and open it on an Android phone (64-bit ARM, which covers almost every phone from the last several years). Allow "Install unknown apps" when asked. If Play Protect offers to scan the app, tap **Scan app**, then install.

**SHA-256:** `aaec91882a5490279409f6ba6eece1b25d695257928a3c74b79cbb5cce9bc53b`

## Permissions

| Permission | Why |
|---|---|
| Internet, network state | Download media |
| Notifications, foreground service, wake lock | Show download progress and keep downloads running |
| Run at startup | Resume unfinished downloads |
| Storage | Save files on older Android versions |

## Note

Only download content you own or have permission to save, and follow the terms of the sites you use.
